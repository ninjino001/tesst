\chapter*{Abstract}

Airport equipment maintenance management is a strategic challenge to ensure the safety, availability, and performance of infrastructures. Given the limitations of traditional corrective approaches and the lack of an integrated intelligent monitoring tool, this internship project proposes the design and implementation of the \textbf{AIMOS} platform (Airport Intelligent Maintenance Operations System).

AIMOS is an intelligent maintenance web platform designed for Moroccan airports, developed during an internship at \textbf{ONDA} (Office National Des Aéroports). It covers the entire maintenance cycle: equipment and sensor management, intervention planning and tracking with maintenance checklists, real-time monitoring through an automatic alert system, and an artificial intelligence module for predictive maintenance.

The technical architecture is based on a Django REST Framework backend, a React frontend with Vite, a PostgreSQL database, all orchestrated via Docker Compose and deployed in production with Nginx and Gunicorn. Four user roles were identified and implemented: Administrator, Supervisor, Maintenance Manager, and Technician.

The results demonstrate a functional platform offering role-differentiated dashboards, an automatic alert system based on sensor thresholds, a failure prediction module using linear regression and z-score anomaly detection, and a real-time notification system.
